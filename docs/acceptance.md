实机使用同一 ARM64 公共用户态产物。BE200 内核为 `6.1.115-gd2eccb6c9eff-dirty`，RTL 内核为 `6.1.115-g847bc9cd7ecd-dirty`；配置数据频率均为 5745 MHz。iPad 分别使用两个保留的 bundle 身份和既有配对连接。

服务就绪后立即重启的检查覆盖退出信号与内核接口释放。最终安装的 wifiawared、fileserver 均 active/enabled；共享目录、已有配对和原 I/O 期限保留。新构建的内核模块完成暂存安装，实机验证使用各设备现有 main 驱动。

## 已知限制

- 新配对、整机重启、吞吐和长期可靠性不属于上表已完成的验收范围。
- 一个守护进程管理一块网卡，使用固定 nan0/ndi0。BE200 backport 替换 cfg80211/mac80211，两个硬件包不能据此视为可同时运行。
- RTL 仅支持一个活动数据站点，活动站点不支持更换为不同密钥。
- U2 重建使用带 MIPS16 后端的 Clang 21 与 GNU MIPS binutils；固件下载格式要求原项目的摘要处理与数组长度核对。
- BE200 原 main 的 Rust 真机结果包含低速 NDP 与连接超时案例，尚无 30 分钟持续验收。RTL 原 main 已完成连接后调度与退出修复，长期连接可靠性和持续性能仍需对应设备证据。
